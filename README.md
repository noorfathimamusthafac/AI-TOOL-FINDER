## 🛠️ Technology Stack

- **HTML5**: Semantic and accessible markup
- **CSS3**: Custom properties (CSS variables), vibrant gradient accents, and responsive layout
- **Vanilla JavaScript**: Lightweight modular logic with no external frameworks
- **JSON**: Structured storage for AI tools data
- **LocalStorage**: Persistent client-side preference and favourites storage

## 💻 How to Run Locally

Open [index.html](index.html) in your browser:
- Double-click `index.html`, or
- Use VS Code Live Server, or
- Run `python -m http.server 8000` and visit `http://localhost:8000`.
